# Shorts library door

Personal-use GitHub Pages door for the Shorts library.

- This repository does **not** contain videos, cookies, or the library files.
- The page is password-gated (AES-GCM). After unlock it only reveals a private
  path to the live library on the home Tailscale network.
- Playback still requires Tailscale and the machine that hosts the library.
- The password is stored only on the host machine, not in this repo.

Pages URL: https://algowise-ai.github.io/shorts-library/
